# Security policy

This project will process potentially sensitive academic work. Do not deploy the development defaults to production.

## Baseline rules

- Never commit API keys, database passwords or student documents.
- Treat uploaded documents as untrusted input.
- Apply file-size and type limits.
- Keep similarity evidence separate from AI-generated interpretation.
- Do not use AI-writing indicators as automatic disciplinary proof.
- Define retention and deletion policies before storing real student submissions.

For security reports, use a private channel rather than a public issue when exploitation details or sensitive data are involved.
